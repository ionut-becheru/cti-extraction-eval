# What Works, What Fails, and What Translation Breaks — artifact

Code, configuration and results behind *From Dark-Web Text to Threat Intelligence: What Works, What Fails, and What Translation Breaks* (RoEduNet 2026). Cite the tagged revision given in the paper.

## Where to find what the paper refers to

| Item | Location |
|---|---|
| Coarse-label mapping (fine label → 13 coarse types, excluded types marked) | `data/gold_ner/label_map.json` |
| Corpus and split identifiers | original train/dev/test files of each corpus, loaded by `scripts/gold_ner/load_gold.py`; counts per split and type in `data/gold_ner/stats.json` |
| Relevance sets (500 held-out positives, Wikipedia and Stack Exchange negatives) | `data/relevance/*_ids.jsonl` (record index or URL of every record; seeds in `scripts/relevance/`) |
| Prompts and type descriptions of the zero-shot and LLM extractors | `scripts/gold_ner/llm_ner.py` (`build_prompt`), `scripts/gold_ner/zeroshot_span_ner.py` (`LABELS`) |
| Translation, noise and masking settings | `scripts/noise/make_noisy_sets.py`, `scripts/mt/mt_ioc_integrity.py`, `scripts/mt/placeholder_styles.py` |
| Scoring (strict/relaxed, bootstrap CIs, transfer conventions) | `scripts/gold_ner/ner_metrics.py`, `scripts/gold_ner/finetune_ner.py` |
| Per-run metrics with 95% bootstrap CIs, wall time and GPU memory | `runs/<ID>/metrics.json`, `runs/<ID>/run_meta.json` |
| Table generation | `scripts/aggregate_tables.py` → `paper_tables/*.tex`, `tables.md`, `paper_numbers.json` |

| Pinned environment | `env/requirements.txt`, `env/ENVIRONMENT.txt` |
| The evaluated regex+gazetteer extractor (unmodified pipeline code) | `baseline/` |
| Pipeline configuration used by the gazetteer audit (`nlp` section; key fields are empty) | `runs/B0_asrun/config.yaml` |

Run IDs → tables: N0 → T1; E2_ft, E3_zs, E4_llm → T2, T3; E5_noise → T4; E6_relevance → T5; E7_hybrid → T8; E8_mt_ioc → T9–T11.

## Regenerating

`python scripts/aggregate_tables.py` rebuilds every table from the shipped `runs/` metrics (no GPU needed). `./run_all.sh` re-runs the full sweep (one 24 GB+ GPU, about 4–6 hours): it downloads the five corpora from their original sources, converts them with `load_gold.py`, and then runs each experiment. Seeds: training 13/17/19, bootstrap 0, noise 0, relevance sampling 42, hard-negative sampling 0.

## Verification

On 2026-11-02 a fresh copy of this repository re-downloaded the five corpora from their original sources (the DNRTI archive matched the one used for the paper by checksum), and `scripts/gold_ner/load_gold.py` reproduced `data/gold_ner/stats.json`, `label_map.json` and all five test splits byte for byte. `scripts/gold_ner/eval_dictionary_ner.py` run from this copy reproduced the micro-F1 of Table I on every corpus (0.2429, 0.2497, 0.1487, 0.3031, 0.1170). `scripts/aggregate_tables.py` regenerates every table in `paper_tables/` identically from the shipped metrics.

## Not included

- The gold corpora themselves. CyNER (MIT), AnnoCTR (CC BY-SA 4.0) and AttackER (CC BY 4.0) are downloaded by the runner; APTNER and DNRTI state no licence and are likewise fetched from their original repositories, never redistributed here.
- Per-sentence predictions and fine-tuned checkpoints (regenerated by the runner).
- The relevance-set texts: the identifiers are shipped; the hard negatives are rebuilt from the Stack Exchange dumps by `scripts/relevance/build_hard_negatives.py`, the positives by `scripts/relevance/export_positives.py` from the rebuilt public corpus, the Wikipedia leads from the listed URLs.
- The thesis-pipeline runs on the full public corpus (database, records, logs); only the KEV-overlap counts that Section IV-F uses are kept.
- Anything from the confidential forum corpus used in Section IV-E. The figure reported there is a disagreement rate on data that is not public.
